# Gems and Treasures

**Gems and Treasures** is a Minecraft 1.12.2 mod focused on adding new gemstones, ores, decorative blocks, treasures, materials, and unique ways to obtain them.

The mod is designed to expand Minecraft's resource progression while giving rare materials their own mechanics and uses.

## Features

- 💎 New gemstones and precious materials
- ⛏️ New ores and resource blocks
- 🧱 Decorative gem and mineral blocks
- ⚒️ New tools, weapons, and armor
- ✨ Unique methods of obtaining rare materials
- 🌋 Resources distributed across the Overworld, Nether, and other environments
- 👹 New mobs and drops
- 🔥 Special processing and crafting mechanics
- 🧩 Optional integrations with other mods

## Carbonado

Carbonado, also known as **black diamond**, can be found embedded in bedrock. It can be mined with a **diamond pickaxe or better**, and equipment crafted from it is slightly stronger than diamond.

Mining carbonado ore from bedrock will drop a **Carbonado Cluster**. These clusters can be broken by dropping an **anvil** on them. The higher the anvil falls from, the more **Raw Carbonado** the cluster can produce.

Carbonado Clusters can also be smelted in a furnace, producing **Carbonado Gems**, which are used to craft carbonado armor and tools.

In the Nether, **Dark Ghasts** can be found roaming the skies. These creatures can drop **Carbonado Shards**, which can be used to craft Carbonado. They can also drop gunpowder and Blaze-related materials.

## Mod Integrations

Gems and Treasures provides optional integrations with other mods.

Currently supported integrations include:

- [Chisel](https://www.curseforge.com/minecraft/mc-mods/chisel)
- [ConnectedTexturesMod (CTM)](https://www.curseforge.com/minecraft/mc-mods/ctm)

These integrations are optional and can be disabled through the mod's configuration.

## Configuration

Gems and Treasures provides configuration options that allow individual features and materials to be enabled or disabled.

This allows modpack authors to customize which resources and features are available in their world.

## Minecraft Version

**Minecraft:** 1.12.2  
**Forge:** 14.23.5.2860+

## Installation

1. Install Minecraft 1.12.2.
2. Install the appropriate version of Minecraft Forge.
3. Download the Gems and Treasures `.jar`.
4. Place the `.jar` file in your `mods` folder.
5. Launch Minecraft.

Some optional integrations may require their respective mods to be installed.
